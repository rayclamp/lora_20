# FESTIVAL RECORD SCHEMA

Each F001–F048 record is the festival-level source of truth.

## REQUIRED FIELDS

- FESTIVAL_ID
- NAME_EN
- NAME_ZH
- REGION / CULTURAL_SCOPE
- SEASON
- CATEGORY_LINKS

## PLANNED DETAIL FIELDS

- CULTURAL_CONTEXT
- CLOTHING
- ACCESSORIES
- SOCKS
- SHOES
- HEADWEAR
- HAIRSTYLE
- MAKEUP
- BODY_DECORATION
- PROPS
- OTHER
- SCENE
- LOCATION
- ACTIVITY
- DECORATION
- FOOD
- SYMBOLS
- HAND_INTERACTION
- CULTURAL_SENSITIVITY (LOW / MEDIUM / HIGH / VERY HIGH)
- RECOGNIZABILITY (LOW / MEDIUM / HIGH / VERY HIGH)

## WORKER RULE

Festival-level data defines the cultural boundary. Category item records provide reusable generation components. Workers may choose composition, camera, pose, action, and visual storytelling independently, but must stay inside verified cultural data.
