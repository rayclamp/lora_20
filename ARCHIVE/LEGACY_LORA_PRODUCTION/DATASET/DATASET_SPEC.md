# LoRA Dataset Specification

## Purpose
Define useful age-20 Inaria LoRA training data.

## Principles
- one primary Inaria instance per image unless an explicit current rule allows otherwise;
- identity consistency;
- natural body proportions;
- strong hand/foot stability;
- varied but controlled composition;
- varied hairstyle, clothing, scene, pose, camera, and lighting;
- avoid near-duplicate images.

## Framing
FULL-BODY ≠ DISTANT SHOT.

Use deliberate variety:
- CLOSE-UP;
- BUST / HALF-BODY;
- MEDIUM SHOT;
- CHARACTER-DOMINANT FULL-BODY;
- ENVIRONMENTAL FULL-BODY when useful.

Do not build a mannequin-sheet dataset.

## Anatomy
CORE anatomy rules are hard constraints. A visually attractive image with obvious anatomy failure is not useful training data.
