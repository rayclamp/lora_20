# LoRA QA Specification

This is the LoRA-specific acceptance profile used by the independent QA module.

Check:
- age-20 identity consistency;
- current LoRA reference/style consistency;
- natural body proportions;
- hand/finger stability;
- foot/toe stability;
- object/wearable connections;
- task framing;
- useful dataset diversity;
- severe artifact/duplicate-body errors;
- accidental animals/pets unless explicitly allowed by a current task rule.

Visible evidence only. Occlusion that prevents reliable judgment → REVIEW.

Generation SUCCESS is not QA PASS.
