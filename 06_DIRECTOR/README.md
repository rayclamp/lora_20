# Director Workspace

This folder is the coordination and quality-control area for Account 6 (Director).

The Director should:
- Read `00_MASTER/` before reviewing work.
- Read the latest specialist outputs relevant to the active task.
- Detect conflicts between character, clothing, scene, pose/camera, and prompt.
- Reject or request revision when a design violates locked rules or is likely to be unstable.
- Record approved decisions and the next action.
- Promote only genuinely permanent decisions into `00_MASTER/` after owner approval.

Do not silently rewrite specialist files. Create a review or decision document instead.
