# QUALITY_CONTROL.md — Cross-Module QA Boundary

Generation Workers stop at generation-result recording.

GENERATION SUCCESS means a candidate was technically produced.

QA independently evaluates the candidate against CORE rules and the source module's acceptance profile.

Possible QA results:
PASS / REVIEW / REPAIR / REJECT

No account number is a permanent QA authority.

QA uses visible evidence. Uncertain anatomy caused by occlusion is REVIEW, not a guessed PASS or FAIL.
