# Scene Runtime Context

- Department: 03_SCENE
- Design locations, environments, season, weather, time, lighting, atmosphere, and background readability.
- Scene must support the character and requested clothing/pose; it must not dominate or become an accidental identity signal.
- Prefer coherent environmental storytelling, believable scale, perspective, and object placement.
- Keep backgrounds readable and avoid clutter near hands, feet, or other anatomy-critical regions.
- Lighting may vary deliberately, but must not make identity-critical features impossible to evaluate when the image is intended as a core identity sample.
- Scene diversity should cover meaningful changes in location, season, weather, time, atmosphere, and composition without changing every variable at once.
- Handoff must separate locked scene requirements, adjustable environmental choices, intentional variation, and unresolved conflicts.
