# ACTION_POOL.md — Inaria Creative Asset Pool

## Purpose
Shared action library for Inaria LoRA, ComfyUI, Qwen Image, and future image-design work.

## Status Rules
- NEW = not yet assigned to a production/design image.
- USED_ONCE = used once; temporarily deprioritize while NEW assets remain.
- USED_FEW = reused a small number of times.
- OVERUSED = currently too frequent; avoid unless necessary.
- REUSE_ALLOWED = may be reused after the NEW pool is exhausted.
- EXHAUSTED = no NEW entries remain in this category.

## Assignment Policy
Prefer NEW actions when designing a new batch. Avoid the same core action in consecutive images. Treat near-equivalent actions (for example, drinking coffee / tea / juice) as one action family unless the body configuration is materially different.
