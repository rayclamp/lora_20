# Inaria AI Studio — Clothing Department Specification

- **Department:** ② Clothing Design
- **Version:** v001
- **Last Updated:** 2026-09-05
- **Purpose:** 建立可長期使用的依娜莉亞（Inaria）20 歲人物身份 LoRA 訓練資料之服裝、鞋履、配件、季節、場景與風格設計規格，供服裝部門及後續 Scene、Pose/Camera、Prompt/Generation、Director/QA 部門協作使用。

---

## 1. Department Mission

服裝部門的核心任務不是讓每張圖片都穿得華麗，而是在**不削弱依娜莉亞人物身份一致性**的前提下，建立足夠多樣、可生成、可辨識、可互相區分的服裝資料。

核心原則：

> **人物身份固定，服裝與外部條件變化。**

服裝設計必須服務於 LoRA 的人物身份學習，而不是讓 LoRA 將人物與某一套固定衣服、固定色彩、固定鞋子或固定場景綁定。

依據專案 MASTER：角色身份、比例與人體結構優先於服裝效果；生成穩定性優先於過度複雜的造型。`00_MASTER/` 為穩定規則來源，永久規則不得由服裝部門自行改寫。

---

## 2. Locked Character Constraints

服裝部門不得自行修改以下角色核心條件：

- 依娜莉亞（Inaria）人物身份。
- 任務指定的年齡版本；本文件服務的主要目標為 20 歲版本。
- 臉型、五官與人物辨識度。
- 藍色眼睛。
- 深藍黑色核心髮色。
- 整體身材比例、肩腰臀比例、四肢比例與頭身比例。
- 正常人體結構。
- 每隻手五根手指、每隻腳正常五趾的硬性要求。

髮型亦屬角色設計的重要變量。除非帳號①或 Director 明確指定，服裝部門不得自行以服裝需求為理由改變已鎖定髮型。

服裝、鞋子、飾品、包袋與造型配色可以依圖片任務改變，但不得藉此改造人物身份。

## 3. Clothing Design Philosophy

### 3.1 Identity vs. Clothing

人物身份是固定訊號；服裝是可變訊號。

因此：

- 不使用單一服裝作為依娜莉亞的唯一代表造型。
- 標準立繪服裝只能作為身份參考，不應成為資料集中的壓倒性服裝。
- 水藍色與藏青色是偏好色，但不是人物身份本身。
- 必須主動使用白、米白、淺灰、淺粉、淡紫、黑、牛仔藍等自然色彩。
- 不應讓所有圖片共享相同領口、裙長、鞋型、材質或裝飾語言。

### 3.2 Design Priority

服裝設計優先順序：

1. 不破壞人物身份。
2. 符合年齡與自然人體比例。
3. 符合季節與場景。
4. 生成結構穩定、容易正確渲染。
5. 與髮型、鞋子、配件形成完整造型。
6. 與其他訓練圖保持差異。
7. 最後才增加複雜裝飾與視覺華麗度。

---

## 4. Dataset Diversity Rules

每張訓練圖至少應與其他樣本改變 2–4 個外部因素。服裝部門尤其應輪換：

- 上衣款式
- 下身款式
- 連身裙輪廓
- 外套
- 鞋子
- 配件
- 主／副色
- 材質
- 季節
- 場景
- 髮型

避免連續樣本只更換顏色而保留完全相同的版型。

避免以下高重複模式：

- 同一件上衣 + 不同裙子大量重複。
- 同一件洋裝只改顏色。
- 同一雙鞋貫穿大部分資料。
- 每張都使用水藍／白配色。
- 每張都露鎖骨、細肩帶、短裙等相同剪裁語言。
- 每張都使用相同飾品位置。

## 5. Seasonal Direction

### 5.1 Spring

關鍵詞：輕盈、柔和、清新、花季、微涼。

推薦：

- 薄棉或輕薄針織上衣。
- 襯衫、薄長袖、輕薄罩衫。
- 中長裙、A-line skirt、百褶裙。
- 輕薄春季洋裝。
- 輕量風衣或短版薄外套。
- 樂福鞋、芭蕾鞋、低跟鞋、乾淨的休閒鞋。

色彩可使用：米白、淺藍、淡粉、淡紫、嫩灰、奶油色、牛仔藍。

避免讓所有春季樣本都使用櫻花粉色；花季只是場景，不是固定服裝顏色。

### 5.2 Summer

關鍵詞：透氣、輕量、自然、清爽、休閒。

推薦：

- 短袖襯衫、無袖上衣、簡潔背心式上衣。
- 輕薄長裙、A-line skirt、半身裙。
- 寬褲、直筒褲、九分褲。
- 夏季連身裙。
- 輕薄短版外套僅在場景合理時使用。
- 涼鞋、帆布鞋、樂福鞋、簡潔平底鞋。

色彩可使用白、淺灰、淺藍、米色、牛仔藍、淡粉、藏青等。

夏季造型應注意透氣與輕量材質，不應讓所有樣本變成同一種短洋裝。

### 5.3 Autumn

關鍵詞：層次、溫暖、成熟但仍符合 20 歲自然成年感。

推薦：

- 襯衫 + 長裙。
- 薄針織 + 半身裙。
- 針織上衣 + 寬褲。
- 長袖洋裝。
- 薄風衣、短外套、針織外套。
- 樂福鞋、短靴、乾淨休閒鞋。

色彩可增加：焦糖、灰棕、酒紅、深綠、奶茶、藏青、米白，同時保留少量水藍作呼應。

### 5.4 Winter

關鍵詞：保暖、層次、材質、簡潔輪廓。

推薦：

- 高領針織。
- 長袖襯衫搭配針織層次。
- 毛衣 + 長裙。
- 毛衣 + 寬褲。
- 長版大衣、羊毛外套、短版保暖外套。
- 厚襪搭配樂福鞋或短靴。
- 長靴僅適量使用，避免成為固定人物特徵。

色彩可使用奶油白、灰、深藍、黑、酒紅、棕、米色等。

冬季設計應避免所有樣本都以大衣包覆人物，需保留不同室內與室外層次。

## 6. Style Direction

### 6.1 Japanese-inspired

核心：乾淨、自然、柔和、細節精緻、低侵略性。

可使用：

- 日系休閒服。
- 簡潔襯衫。
- 百褶裙、中長裙。
- 乾淨洋裝。
- 針織上衣。
- 帆布鞋、樂福鞋、芭蕾鞋。
- 小型肩背包、帆布包、簡潔髮飾。

裝飾應以少量細節形成質感，不使用大量複雜蕾絲或堆疊裝飾。

### 6.2 Korean-inspired

核心：俐落、比例清楚、現代約會感、簡潔層次。

可使用：

- 修身襯衫。
- 簡潔針織。
- 長裙。
- 寬褲。
- 短版外套。
- 西裝式外套。
- 低跟鞋、樂福鞋、乾淨球鞋。
- 小型肩背包。

韓系風格可使用中性與低飽和色彩，但不要固定成全黑或全米白。

### 6.3 Modern Taiwan

核心：都市實穿、通勤、便利、自然、符合台灣氣候。

可使用：

- 輕薄襯衫。
- 短袖或薄長袖上衣。
- 寬褲、直筒褲、長裙。
- 夏季洋裝。
- 輕薄外套。
- 通勤樂福鞋、休閒鞋、低跟鞋。
- 小型肩背包、托特包、簡潔通勤包。

夏季需考慮炎熱與潮濕；冬季則依台灣相對溫和的環境調整，不應把所有台灣冬季場景都設計成極厚重雪地服裝。

## 7. Garment Component Rules

### 7.1 Tops

可使用：

- T-shirt
- 短袖襯衫
- 長袖襯衫
- 無袖上衣
- 簡潔背心式上衣
- 針織上衣
- 高領上衣
- 輕薄 blouse

設計要求：

- 領口、袖長、合身程度應輪換。
- 不要讓同一種領口成為固定人物特徵。
- 圖像需要露鎖骨時可以設計，但不應每張都使用相同露鎖骨剪裁。
- 避免過度複雜的蝴蝶結、綁帶、細繩與多層透明結構。

### 7.2 Skirts

可使用：

- A-line skirt
- 百褶裙
- 直筒裙
- 中長裙
- 長裙
- 簡潔傘裙

設計要求：

- 裙長需跨越不同樣本變化。
- 避免所有裙子都有相同蕾絲下擺。
- 注意坐姿、行走與風動時的布料結構可生成性。

### 7.3 Pants

可使用：

- 寬褲
- 直筒褲
- 九分褲
- 牛仔褲
- 西裝褲
- 簡潔休閒褲

設計要求：

- 褲型輪廓需有明顯差異。
- 避免過多複雜口袋、束帶、扣件。
- 長褲可有效降低資料集過度偏向裙裝的風險。

### 7.4 One-piece Dresses

可使用：

- A-line dress
- Shirt dress
- 簡潔襯衫洋裝
- 夏季輕洋裝
- 長袖 midi dress
- 長裙擺連身裙
- 簡潔約會洋裝

設計要求：

- 輪廓、袖型、腰線、裙長與材質必須輪換。
- 標準立繪的淡水藍／白蕾絲洋裝不得成為資料集主導服裝。
- 不以大量蕾絲、蝴蝶結、半透明面料建立固定身份特徵。

### 7.5 Outerwear

可使用：

- 輕薄風衣
- 短版外套
- 針織外套
- 西裝外套
- 羊毛外套
- 簡潔大衣

設計要求：

- 外套不是每張都需要。
- 外套不可長期遮擋人物核心輪廓與臉部。
- 避免過多拉鍊、扣子、肩章、繩帶等小型結構。

### 7.6 Shoes

可使用：

- 芭蕾鞋
- 樂福鞋
- 低跟鞋
- 平底鞋
- 帆布鞋
- 休閒球鞋
- 涼鞋
- 短靴
- 長靴

設計要求：

- 鞋子必須與季節及場景合理。
- 鞋型需要跨樣本變化。
- 避免過度複雜鞋帶與細小金屬結構。
- 若人物全身入鏡，鞋子結構與左右腳方向必須清楚。
- 不得使用鞋子掩蓋嚴重腳部生成錯誤來假裝通過 QC。

### 7.7 Accessories and Bags

可使用：

- 小型肩背包
- 托特包
- 小型斜背包
- 簡潔手提包
- 髮帶
- 髮夾
- 耳環
- 項鍊
- 手錶
- 手鍊
- 簡潔戒指
- 圍巾
- 帽子

設計要求：

- 配件數量適中。
- 不要讓某一件飾品在大多數資料中固定出現。
- 手持物品應優先選擇容易生成且不造成手部遮擋或融合的物件。
- 避免大量細鏈、細繩、複雜扣件等高 artifact 風險細節。

## 8. Age / Scene / Season Matching

### 8.1 Age

20 歲版本應保持**年輕成年女性**的自然感。

服裝可以有成熟、俐落或正式場合造型，但不可透過服裝使角色呈現明顯未成年化或不合理老化。

避免：

- 幼兒化童裝語言。
- 過度成熟的老成職場造型堆疊。
- 與角色年齡明顯不符的極端造型。

### 8.2 Scene

服裝必須與場景功能一致：

| Scene | Recommended direction |
|---|---|
| 咖啡廳 | 日系休閒、韓系約會、簡潔洋裝、針織 |
| 辦公區 | 襯衫、西裝外套、長褲、中長裙、樂福鞋 |
| 車站 | 通勤休閒、針織、長裙、寬褲、休閒鞋 |
| 城市街道 | 現代台灣、日系休閒、韓系都市 |
| 海邊 | 夏季洋裝、輕薄上衣、長裙、涼鞋 |
| 公園 | 休閒服、針織、襯衫、牛仔褲、帆布鞋 |
| 山區 | 輕量戶外、長褲、薄外套、穩定鞋款 |
| 餐廳 | 約會洋裝、襯衫、中長裙、低跟鞋 |
| 室內居家 | 輕便上衣、針織、寬褲、簡潔休閒服 |

此表為方向而非硬性固定配對；應保留合理變化。

### 8.3 Season

季節應與材質、袖長、裙褲長度、外套厚度及鞋款互相支援。

場景若為室內，可合理弱化季節服裝差異；戶外場景則應讓服裝具有明顯季節合理性。

## 9. Clothing Dataset Image Selection Standard

服裝圖片只有在同時滿足以下條件時才建議進入 LoRA dataset：

### 9.1 Identity

- 仍然明確是依娜莉亞。
- 臉部身份沒有被服裝、配件或陰影破壞。
- 核心人物特徵沒有因造型而改變。

### 9.2 Clothing

- 上衣、下身／連身裙、鞋子與配件結構合理。
- 左右服裝結構基本一致。
- 材質與皺褶符合服裝種類。
- 不出現不合理穿模。
- 不出現無法解釋的衣物融合。

### 9.3 Anatomy

- 每隻手五指正常。
- 每隻腳結構正常。
- 無多餘肢體。
- 衣物沒有造成肢體融合或肢體數量誤判。

### 9.4 Diversity

- 不與現有樣本高度重複。
- 至少在服裝、鞋子、配件、顏色或造型組合上具有有效差異。
- 不因單張圖片漂亮而犧牲資料集多樣性。

### 9.5 Image Quality

不得有：

- 嚴重模糊。
- 嚴重 artifact。
- 文字、Logo、水印。
- 嚴重背景遮擋服裝核心結構。
- 過度磨皮或塑膠材質感。

## 10. Common Clothing Generation Errors

常見錯誤包括：

### Structural errors

- 左右袖子數量錯誤。
- 衣領融合進脖子。
- 扣子或拉鍊數量異常。
- 衣服與身體穿模。
- 腰線位置不合理。
- 裙襬突然消失或增加不合理層數。
- 褲管左右不一致。
- 鞋子左右腳型不一致。
- 鞋底方向錯誤。
- 袖口、裙襬、襪口出現不自然融合。

### Detail errors

- 蕾絲變成無法辨識的噪點。
- 花紋在身體不同區域無規則跳變。
- 細繩、蝴蝶結、項鍊互相融合。
- 細小扣件產生 artifact。
- 包袋背帶穿過手臂或身體。

### Identity interference

- 大型帽子或配件遮住臉部。
- 高領、圍巾、外套完全改變頸肩輪廓。
- 服裝顏色或反光導致臉部色調異常。
- 造型過度誇張導致人物看起來像另一個角色。

## 11. Repair vs. Reject Standard

### 11.1 可修復

在人物身份與人體結構基本正確的前提下，可考慮局部重繪／重新生成：

- 小型服裝花紋錯誤。
- 少量布料皺褶不自然。
- 小型扣件、蝴蝶結細節錯誤。
- 鞋面局部細節錯誤但腳部結構正常。
- 包袋位置略不自然但不造成肢體融合。
- 小範圍衣物 artifact。

修復後仍必須重新進行完整 QC。

### 11.2 應淘汰

出現以下情況，不應作為 LoRA 訓練資料：

- 臉部身份嚴重錯誤。
- 人物年齡感嚴重錯誤。
- 身材比例嚴重錯誤。
- 多餘手臂或腿。
- 手指嚴重錯誤。
- 腳部嚴重錯誤。
- 衣服與人體大面積融合。
- 無法辨識原本服裝結構。
- 嚴重 AI artifact。
- 文字、Logo、水印。
- 服裝造成角色身份明顯漂移。
- 與其他訓練圖高度重複，且沒有足夠資料價值。

原則：

> **不要用修圖掩蓋會被 LoRA 學習的結構性錯誤。**

## 12. Clothing Prompt Standard

服裝部門提供的 Prompt 應採模組化結構，方便後續帳號整合：

```text
[character identity],
[hair if explicitly assigned],
[top],
[bottom or one-piece dress],
[outerwear if any],
[shoes],
[accessories and bag],
[seasonal/material cues],
[scene compatibility cues],
[quality/style constraints]
```

### Recommended English format

```text
inr20, 1girl,
[hair],
[top], [bottom or dress], [outerwear],
[shoes], [accessories], [bag],
[seasonal/material details],
[style direction]
```

服裝 Caption 與 Prompt 應優先描述**該圖片真正存在的服裝變化**，不要為了增加文字而加入不存在的服裝細節。

### Example

```text
inr20, 1girl, high ponytail, white short-sleeve blouse, navy pleated midi skirt, beige loafers, small shoulder bag, simple silver earrings, spring, Japanese-inspired casual style
```

另一例：

```text
inr20, 1girl, long straight hair, light gray knit sweater, blue wide-leg trousers, white sneakers, small crossbody bag, autumn, modern Taiwan casual style
```

## 13. Clothing Caption Rules

依專案既有 Caption 統一規格，Trigger Word 為 `inr20`。

服裝相關 Caption 原則：

1. 使用實際生成的服裝描述。
2. 描述髮型時，僅在該圖片或任務已指定且允許時加入。
3. 描述服裝版型、顏色與主要配件。
4. 不重複塞入所有固定人物核心特徵。
5. 不加入圖片中不存在的服裝。
6. 不使用含糊或互相矛盾的服裝詞。
7. Caption 長度以能清楚區分該樣本為原則，不追求無限制增加 token。

## 15. Design Risk Management

### Low risk

- 簡潔 T-shirt / blouse。
- 單純長裙。
- 直筒褲／寬褲。
- 簡潔洋裝。
- 樂福鞋、帆布鞋、平底鞋。
- 小型肩背包。

### Medium risk

- 百褶裙。
- 針織層次。
- 西裝外套。
- 短靴。
- 複合式配件。
- 輕量蕾絲。

### High risk

- 大量細蕾絲。
- 多層半透明布料。
- 大量細繩／綁帶。
- 複雜胸針與鏈條組合。
- 多層裙襬互相重疊。
- 極端寬大袖子。
- 大量小型扣件。
- 手持複雜物件並同時要求複雜手勢。

High-risk design 並非禁止，但必須有明確資料價值，且生成後需進行更嚴格 QC。

## 16. Practical Distribution Guidance

服裝部門在規劃整套 LoRA dataset 時，應追求以下方向，而非機械固定比例：

- 裙裝與褲裝都必須有足夠代表性。
- 連身裙應有多種輪廓，而非同一洋裝換色。
- 春夏秋冬均應出現合理樣本。
- 日系、韓系、現代台灣等風格均應有代表性。
- 正式、休閒、約會、通勤、戶外、居家等場合應分散。
- 鞋子與配件必須有明顯變化。
- 水藍色可以作為 recurring accent，但不得壓倒其他色彩。
- 標準立繪服裝不得成為資料集的主要服裝。

具體圖片比例應由整體 dataset 規劃與 Director 最終決定；本規格不覆寫 MASTER 對資料多樣性的要求。

## 17. Final Clothing QC Checklist

每一套服裝完成後，服裝部門應逐項確認：

### Character
- [ ] 仍為指定版本的依娜莉亞。
- [ ] 臉部身份未被服裝影響。
- [ ] 年齡感合理。
- [ ] 身材比例正常。

### Clothing
- [ ] 上衣結構正常。
- [ ] 下身／連身裙結構正常。
- [ ] 外套結構正常（如有）。
- [ ] 鞋子左右結構正常。
- [ ] 配件數量合理。
- [ ] 包袋結構正常。
- [ ] 沒有明顯穿模或融合。

### Anatomy
- [ ] 每隻手五指正常。
- [ ] 每隻腳結構正常。
- [ ] 沒有多餘肢體。
- [ ] 沒有被服裝掩蓋的結構性錯誤。

### Dataset
- [ ] 與其他樣本有足夠差異。
- [ ] 沒有固定服裝綁定風險。
- [ ] 色彩沒有過度集中。
- [ ] 場景／季節搭配合理。

### Image Quality
- [ ] 無嚴重模糊。
- [ ] 無嚴重 AI artifact。
- [ ] 無文字。
- [ ] 無 Logo。
- [ ] 無水印。

任何嚴重不符合項目 → **不得進入正式 LoRA dataset**。

## 19. Handoff Summary for Department ⑥

服裝部門的核心交付不是單純的「漂亮服裝清單」，而是：

> **一套能在不同季節、場景、風格與服裝組合中保持依娜莉亞身份一致，同時避免服裝成為 LoRA 固定捷徑的可生成服裝系統。**

服裝設計的最終優先順序：

1. 人物身份一致。
2. 人體與服裝結構正確。
3. 年齡、季節、場景合理。
4. 資料集多樣性。
5. 生成穩定性。
6. 服裝與配件完整度。
7. 視覺華麗程度。
